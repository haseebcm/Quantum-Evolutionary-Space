# Examples Index

## Core examples

- `examples/basic_run.py` — canonical room-population loop
- `examples/control_policy_search.py` — control optimization example
- `examples/design_space_search.py` — engineering design search example
- `examples/intelligent_universe.py` — recursive world/universe composition

## Advanced examples

- `examples/qsee_11l_demo.py` — isolated eleven-stream intelligence flow
- `examples/h11x_closure_demo.py` — admissibility and closure logic
- `examples/genesis_pipeline_demo.py` — selection pipeline behavior
- `examples/production_pipeline.py` — production-like runtime flow
- `examples/scientific_inference.py` — parameter estimation example
- `examples/resource_allocation.py` — compute budget allocation example
- `examples/runtime_scheduler_demo.py` — priority scheduler and telemetry example
- `examples/distributed_runtime_demo.py` — multi-worker durable runtime example
- `examples/scipy_baseline_benchmark.py` — QES governed search vs. an external
  SciPy optimizer baseline on the standard Rosenbrock benchmark function
  (requires `pip install scipy`)
